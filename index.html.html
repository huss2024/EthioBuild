▼ 3. Resources & Rates

Ethiopian standard units: Cement = ETB per 50kg bag (1 quintal = 100 kg = 2 bags). Rebar resources = ETB per kg (≈ berga for 12m bar shown under each size). BOQ rebar rate = ETB per tonne (1000 kg). Sand/aggregate = ETB/m³ · Labour = ETB/day · Plant = ETB/hour.

1. Resource prices (current market)

Cement, sand, aggregate, labour day rates, equipment hourly rent — edit to match your market.

2. Rate build-up (Material · Manpower · Machinery)

Built from mix ratios (e.g. C25 ≈ 1:2:3), labour with utilization, and machine hours. Linked to BOQ.

Item / mix Material Manpower Machinery Total / unit Unit Detail

Example: C25 concrete uses cement, sand, aggregate (~1:2:3), mixer + vibrator hours, skilled & unskilled labour with utilization factors.

Welcome

How to use EthioBuild

Step-by-step walkthrough for first-time users

For Clients (Users)

  1. Use free — Setup, Takeoff, Rates, BOQ, Summary. Pay only when you Export Excel.
  2. Enter a clear Project Name (this name is what you pay for).
  3. Add floors as G+ and basements; enter area per floor if sizes differ.
  4. Several buildings in one project: under Setup use + Add building / block. Switch the active building, fill its takeoff, then generate BOQ — all buildings combine under the same project name (one payment).
  5. Set concrete grades per member (e.g. slab C-25, columns C-30), rebar schedule, doors/windows/roof specs.
  6. Use Auto-fill then adjust Takeoff. Open Rates to edit material / manpower / machinery or rebuild from resources.
  7. Click Generate BOQ, review Summary, then Export for a professional Excel report.
  8. After payment + unlock code, you can export that same project name anytime free. A new project name needs a new payment.

Tabs

  • Setup — Project name, buildings, GFA, structure, concrete grades, rebar schedule, specs (doors, windows, roof, lifts…).
  • Takeoff — Quantities: structure, finishes, M&E, hospital rooms, site/pool/gas/landscape, escalators, generators…
  • Rates — Resource prices + Material/Manpower/Machinery build-up. Rebuild rates from market prices.
  • BOQ — Bill of Quantities with specs & method of measurement. Editable.
  • Summary — Totals, charts, cost by building.
  • Export — Professional Excel (cover, takeoff, BOQ, rates, rebar schedule, signatures).
  • Saved — Reload drafts and unlocked projects.

Multiple buildings (same project) — clear steps

  1. Use one Project Name for the whole site (one payment when you export).
  2. In Setup → Buildings in this project → + Add building / block.
  3. Rename each (Block A, Clinic, Warehouse…).
  4. Click a building so it is active. Floors, areas, and Takeoff apply only to the active building.
  5. Fill Setup + Takeoff for building A → switch to B → fill B → repeat for every building.
  6. Click Generate BOQ once. All buildings are merged; other buildings’ lines show as [Building name].
  7. Open Summary → Cost by building to see each block’s share of the total.

For the Owner

  1. Click Owner (top right) and enter password (default: ethio2026).
  2. Set Firm name, Phone / Telegram and Telebirr (appears on Excel exports).
  3. Update Market rates and optional online rates URL.
  4. Adjust access pricing rules (base, per m², per floor, minimum).
  5. When a client pays → click Generate Single Code Now → send the code to the client.
  6. Use Export Data / Import Data to move your codes and settings between phone and computer.
  7. Change the password after first use.

Tips

  • Use Auto-fill first, then refine takeoff and the rebar schedule.
  • Set different concrete grades for foundations, columns, beams, slabs and stairs.
  • In Rates, prices use Ethiopian standards: cement ETB/50kg bag (×2 = quintal), rebar ETB/kg (≈ berga), BOQ rebar ETB/tonne. Click Rebuild after changes.
  • Hospital rooms, escalators, generators, pool/gas/landscape are under Takeoff when needed.
  • Work is auto-saved. Everything runs offline after the page loads.
  • Demo unlock code: DEMO2026
